# نظام الهوت سبوت الكامل — راوتر Huawei HG630 V2 + ويندوز

نظام كامل لتحويل راوتر **Huawei HG630 V2 (VER.B)** + أي كمبيوتر ويندوز إلى **هوت سبوت محترف**: بوابة دخول عربية، كروت شحن، باقات بجيجات وسرعات، عدّاد استهلاك حقيقي، قطع تلقائي عند انتهاء الباقة، وقت نوم/دراسة، حظر أجهزة، وتقارير — بدون أي أجهزة إضافية.

## المكونات

| الجزء | الوظيفة |
|---|---|
| راوتر HG630 V2 | نقطة واي فاي معزولة (Access Point) — كونفيج مخصص يُرفع للراوتر |
| جهاز الكمبيوتر (ويندوز) | بوابة الإنترنت: توزيع عناوين (ICS)، تحويل تلقائي للبوابة، محرك العدّاد والقطع (WinDivert)، سيرفر الويب والواجهات |
| الموبايلات | تتصل بالواي فاي → صفحة دخول عربية → كارت/يوزر → إنترنت بمراقبة كاملة |

## الميزات

- ✅ عدّاد استهلاك حقيقي لكل جهاز (رفع + تحميل) — يعمل بتقنية اعتراض الحزم WinDivert
- ✅ قطع تلقائي فوري عند انتهاء الباقة (أو تجاوز الحصة اليومية)
- ✅ تحويل تلقائي لصفحة الدخول (Captive Portal) — أي موبايل يتصل يفتح البوابة لوحده عبر DNS ذكي
- ✅ حماية الشبكة المنزلية: مشتركو الواي فاي لا يصلون لراوتر البيت (192.168.1.1) ولا لصفحة الراوتر (.254)
- ✅ جدولة قفل (وقت النوم / وقت الدراسة) مع استثناء أجهزة
- ✅ شاشة أجهزة لحظية: مين متصل، استهلاكه، زر قطع/حظر لكل جهاز
- ✅ تثبيت الكارت على أول جهاز + قائمة حظر MAC
- ✅ تقارير استهلاك يومية + تصدير الكروت CSV
- ✅ اختبار سرعة من صفحة العميل + عرض الرصيد المتبقي لحظياً
- ✅ وضع ليلي للوحة الأدمن + فونت IBM Plex Sans Arabic مدمج (يعمل بدون إنترنت)

## المتطلبات

1. راوتر **Huawei HG630 V2** هاردوير `VER.B` بسوفتوير `V100R001C36B023` (نفس إصدار 3BB المفتوح)
2. كمبيوتر ويندوز 10/11 فيه:
   - كارت إيثرنت (يوصل بالراوتر بكابل) + اتصال إنترنت (واي فاي أو غيره)
   - صلاحيات أدمن
3. **ملاحظة أمان مهمة:** كونفيج الراوتر المرفق يقفل SSH/Telnet وإدارة الراوتر على الجهاز المشغل فقط — لو احتجت ترجع للإعدادات الافتراضية اضغط زر Reset 10 ثواني.

## التركيب (5 دقائق)

### الخطوة 1 — كونفيج الراوتر (مرة واحدة)
1. وصّل الكمبيوتر بالراوتر بكابل.
2. شغّل `Apply_Upgraded_Config.ps1` (كليك يمين → Run with PowerShell) — هو بيرفع `backups\curcfg_upgraded_signed.conf` للراوتر والراوتر يعمل ريستارت.
3. بعد الريستارت الراوتر يبقى على `192.168.2.254` وواي فايله:
   - `3bb-wlan` (للأدمن) — الباسورد الافتراضي: `HG630!Admin-2026`
   - `Huawei-Guest-Basic` (للمشتركين، معزولة) — الباسورد الافتراضي: `12345678`
4. **غيّر الباسوردات من ملف `Huawei_Config_Engine.ps1`** (أعلى الملف: `PrimaryPass` و `SSID2Pass`) ثم أعد بناء الكونفيج ورفعه:
   ```powershell
   powershell -File Huawei_Config_Engine.ps1 -Action BuildUpgradedConfig -InputFile backups\curcfg_backup_original.conf -OutputFile backups\curcfg_upgraded_signed.conf
   powershell -File Apply_Upgraded_Config.ps1
   ```

### الخطوة 2 — الكمبيوتر
1. وصّل الكمبيوتر بالإنترنت (واي فاي) وبالراوتر (كابل إيثرنت).
2. شغّل `Install.bat` **كمسؤول** — هو بيضبط:
   - مشاركة الإنترنت (ICS) على `192.168.2.1`
   - تاسك تشغيل تلقائي لمحرك الحماية (مرتفع الصلاحيات)
   - تشغيل تلقائي لسيرفر الويب عند كل تسجيل دخول
3. افتح `http://192.168.2.1` — لوحة الأدمن (`admin` / `3BB` — غيّرها من تبويب النظام).

### الخطوة 3 — جرب من موبايل
1. اتصل بـ `Huawei-Guest-Basic`.
2. صفحة الدخول هتفتح لوحدها (أو افتح `192.168.2.1` يدوياً).
3. أدخل كارت من لوحة الأدمن (تبويب الكروت → توليد).

## كيف يعمل العدّاد والقطع؟

محرك `Gateway_Engine.ps1` يستخدم **WinDivert** لاعتراض كل حزم أجهزة الواي فاي عند بوابة الكمبيوتر:
- يعدّ كل بايت (رفع/تحميل) لكل جهاز ويحدّث قاعدة البيانات كل دقيقة.
- الجهاز غير المفوّض: أي استعلام DNS يرد عليه بعنوان البوابة → الموبايل يفتح صفحة الدخول تلقائياً، وأي ترافيك آخر يُسقط.
- انتهاء الباقة أو الحصة اليومية أو وقت النوم أو الحظر → **إسقاط فوري للحزم** (قطع حقيقي ليس مجرد واجهة).
- أي محاولة وصول لشبكة البيت الداخلية أو صفحة الراوتر تُسقط نهائياً.

> **حدود تقنية صريحة:** تحديد السرعة لكل مستخدم على ويندوز تقريبي (الخنق عبر التأخير يُطبق لكل باقة لكنه ليس بدقة tc في لينكس). العدّاد والقطع والحماية دقيقة 100%.

## الأسئلة الشائعة

**الراوتر بقى مش مفتوح بعد الفلاش؟** — الإدارة على `192.168.2.254` ومن الكمبيوتر المشغل فقط (ACL). للرجوع الكامل: زر Reset 10 ثواني يرجع كل حاجة لوضع المصنع.

**عايز أوقف كل النظام مؤقتاً؟** — `Stop-Service SharedAccess` يوقف بوابة النت، أو أوقف تاسك `Huawei_Gateway_Engine`.

**بياناتي فين؟** — `Huawei_Arabic_System/data/db.json` (كروت/مستخدمين/باقات) + `data/history/` (تقارير). اعمل نسخة احتياطية منها دورياً.
